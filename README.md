# Football Statistical Analysis

This project performs statistical analysis on a football dataset using Python.

## Dataset
The dataset contains football match statistics between 2015 and 2025.  
The analysis focuses on the **"Shots (Home)"** variable.

## Features
The project calculates several statistical metrics including:

- Mean
- Median
- Variance
- Standard deviation
- Standard error
- Confidence intervals
- Hypothesis testing
- Outlier detection using the IQR method

## Data Visualization

The project visualizes the data distribution using:

- Histogram
- Boxplot

These visualizations help analyze the distribution and detect potential outliers.

## Technologies Used

- Python
- Pandas
- Matplotlib

## Example Output

The program outputs statistical results such as:

- Sample size
- Mean and median values
- Variance and standard deviation
- Confidence intervals
- Hypothesis testing results
- Outlier detection
